# SOP: Client onboarding (days 0-14)

Owner: account lead. SLA: kickoff within 5 business days of signed scope.

## Day 0 (paid)
- Confirm payment or first invoice date in writing.
- Create a client folder: scope, access, weekly, invoices.
- Send kickoff email (templates/kickoff-email.md).

## Day 1
- Collect access list (templates/access-list.md). Missing items go on a single blocker list, not Slack scatter.
- Book a 45-minute kickoff. Agenda: goal, out-of-scope, weekly slot, who approves.

## Day 2-3
- Write a one-page working agreement: goal, 3 deliverables, not-included, weekly cadence.
- Client replies "approved" on that page before production work.

## Day 14
- Run first-14-days checklist. If access still missing, pause production (templates/pause-work.md).
