# SOP: Proposal

One proposal = one problem, one scope, one price. No optional 12-page decks.

1. Restate the problem in one sentence the buyer used.
2. Scope: 3 bullets they get, 3 bullets they do not get.
3. Price: one number, USDC or their usual currency. Payment schedule: 50% start / 50% delivery, or monthly retainer.
4. Timeline: start date + first visible artifact.
5. Send as a one-pager (templates/proposal.md). Follow up day 3 and day 7, then close the file.
